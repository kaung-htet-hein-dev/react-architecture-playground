# React Internal

An interactive guide to what React does under the hood, written for junior developers who already use useState, keyed lists and useEffect. Ten chapters follow one click through the loop of trigger, render, reconcile and commit. Each chapter explains an idea and then lets you step through a simulation of it. The Playground runs ten presets with editable values. Every simulation is generated by a small fiber model, so none of the frames are drawn by hand.

## Routes

- `/`: the guide, one scrolling page with chapters 1–10 (`#ch1` … `#ch10`)
- `/playground`: full-screen Playground with fiber trees, queues, hook slots, effects and a frame timeline. Supports `?preset=<id>&step=<n>`
- `/dev/components`: sheet of the shared components, used to compare them with the design

## Stack

React 19, React Router, Tailwind CSS v4, Motion, Vite, TypeScript and Vitest. The React Compiler is enabled through the Babel plugin, so components don't need manual memoization. There is no backend, and the build deploys as static files.

## Scripts

```sh
pnpm install
pnpm dev        # start the dev server
pnpm build      # type-check and build
pnpm preview    # serve the production build
pnpm lint       # run ESLint
pnpm test       # run the Vitest suite once
```

## Where things live

- `src/app/`: routes, settings (reduced motion from the OS), chapter list and loop-indicator mapping
- `src/pages/Course.tsx`, `src/pages/course/`: the guide page and one component per chapter (chapter-only parts in `chN/`)
- `src/pages/Playground.tsx`, `src/pages/playground/`: the Playground page and its panes
- `src/components/`: shared UI (top bar, sidebar, CodePane, ComponentTree, SimControls, DomLog, LivePreview, FrameTimeline, Workbench) with primitives in `ui/`
- `src/content/`: glossary, quiz, myths, summaries and code samples
- `src/sim/model/`: the fiber model (update queues and lanes, render with bailouts, keyed reconciliation, commit, effects)
- `src/sim/scenarios/`: one scenario per chapter and per Playground preset (`playground/`). Each is a pure `(params) => Step[]` with Vitest tests next to it
- `src/sim/useSimulation.ts`: playback (play, pause, step, scrub, speed). The UI renders only `steps[index]`
- `src/styles/`: design tokens (`tokens.css`) and global CSS
- `doc/`: requirements, build prompt, design README and the `design/*.dc.html` reference files

## Accessibility

Reduced motion turns on when the OS asks for it (`prefers-reduced-motion`). With reduced motion on, nothing autoplays and nothing transitions, and the trees show numbered render-order badges. Everything can be operated with the keyboard. In the Playground, `→` steps forward, `←` steps back and `Space` plays or pauses.
